Statistical & Exploratory Data Analysis (EDA)

Our Overview

This notebook focuses on performing statistical analysis and Exploratory Data Analysis (EDA) on wind turbine SCADA data. The objective is to understand the dataset, examine sensor measurements, identify patterns and potential anomalies, and explore relationships between variables.

Objectives

- Perform descriptive statistical analysis.
- Explore the distributions of numerical variables.
- Analyze correlations between sensor measurements.
- Perform group-by analysis to compare turbine performance across different categories.

Analysis Workflow

1. Descriptive Statistics

Analyze numerical features using statistical measures such as mean, standard deviation, minimum, maximum, and quartiles to understand the characteristics of the data.

2. Data Distributions

Visualize numerical variables using histograms and boxplots to examine distributions, detect skewness, and identify potential outliers.

3. Correlation Analysis

Investigate relationships between numerical features using correlation matrices, heatmaps, and scatter plots to identify patterns and potential dependencies.

4. Group-by Analysis

Group data by different categories, including turbine assets, operating status, event descriptions, and wind speed ranges, to compare performance and identify patterns.

Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Dataset

Wind Turbine SCADA Data for Early Fault Detection

The dataset contains wind turbine operational measurements and sensor readings used for statistical analysis and performance exploration.

Project Goal

Build a better understanding of wind turbine behavior through data analysis and uncover insights that can support performance monitoring and future predictive maintenance and early fault detection.
